Web_project_coffeeshop_es

Se ha creado la página web de una tienda de café llamada Triple Expresso, donde podrás reservar una mesa mediante un formulario; conocer sus redes sociales para contacto e interactuar con las funcionalidades. Los enlaces y el botón cambian del color al sobreponerse ya que usamos la tecnología del hover para darle el estilo que se merece, las casillas del formulario(input) están bien definidas, ya que usamos las etiquetas(label) para señalizar los campos, e incluso usamos la herramienta "placeholder" para complementar lo que se espera en cada una de ellas. Al final tendrás que llenar todos los campos correctamente y mamrcar la casilla de los terminos de uso, para poder generar tu reserva.

Para la creación de esta página web, utilizamos las tecnologías aprendedias hasta este momento:

🎨 Tecnologías Frontend
HTML5: Estructura semántica del sitio web con elementos modernos
CSS3: Estilos avanzados incluyendo:
Flexbox para layouts responsivos
Grid Layout para estructuras complejas
Transiciones y efectos hover
Pseudoclases (:focus, :hover)

📐 Metodologías CSS
BEM (Block, Element, Modifier): Metodología de nomenclatura CSS para:
Bloques independientes (.form, .header)
Elementos (.form**button, .header**logo)
Modificadores (.form\_\_label_type_checkbox)
Arquitectura CSS modular: División del código en archivos separados por componentes
@import: Conexión de archivos CSS modulares

🔧 Control de Versiones
Git: Sistema de control de versiones para:
Seguimiento de cambios (git add, git commit)
Historial del proyecto
GitHub: Plataforma de colaboración y hosting
