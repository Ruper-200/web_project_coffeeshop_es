# Triple Espresso — Coffee Shop
Página web responsiva para una cafetería ficticia, desarrollada como parte de mi formación en desarrollo Front-End en TripleTen.

El proyecto está enfocado en fundamentos de **HTML5 y CSS3**, incluyendo estructura semántica, diseño responsivo, metodología BEM y construcción de formularios con validación nativa del navegador.

### 🔗 Demo
**[Ver aplicación desplegada](https://ruper-200.github.io/web_project_coffeeshop_es/)**


## Sobre el proyecto
Triple Espresso representa el sitio web de una cafetería donde el usuario puede conocer el establecimiento, consultar contenido relacionado y completar un formulario para solicitar una reservación.

Este proyecto forma parte de mis primeras etapas de formación Front-End y me permitió aplicar fundamentos de maquetación, organización de estilos y construcción de interfaces responsivas.


## Funcionalidades
- Navegación entre las diferentes secciones de la página.
- Formulario para reservación de mesa.
- Validación nativa mediante atributos HTML5.
- Campos correctamente asociados mediante `label`.
- Uso de `placeholder` para complementar las instrucciones de los formularios.
- Enlaces hacia redes sociales.
- Estados interactivos mediante `:hover` y `:focus`.
- Adaptación de la interfaz a diferentes tamaños de pantalla.

## Organización de estilos
El proyecto utiliza la metodología **BEM (Block, Element, Modifier)** para mantener una nomenclatura CSS estructurada y facilitar la separación de responsabilidades entre los diferentes componentes de la interfaz.

Los estilos están organizados en archivos independientes y conectados mediante `@import`, permitiendo mantener una estructura modular.


## Formularios
El formulario de reservación utiliza elementos y atributos nativos de HTML para estructurar y validar la información ingresada por el usuario.

Entre ellos se encuentran:

- `input`
- `label`
- `textarea`
- `placeholder`
- `required`
- diferentes tipos de `input`

La asociación entre etiquetas y campos ayuda a mantener una estructura más clara y accesible.
